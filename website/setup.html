Before your sitter arrives

Set it up

Use the 7-day trial to get the tablet on the wall and the guide filled in. The trial is for setup — not a complimentary stay.

What you need

  • A tablet — 10" or larger works well on a wall. Android is the usual choice if you want Fully Kiosk; an iPad works in the browser or as a home-screen app.
  • Power and Wi‑Fi — the tablet should stay plugged in, with a reliable signal where you mount it.
  • A wall mount — any secure tablet mount you are happy with. We do not sell hardware.
  • About 30 minutes for the setup wizard once your hub is live (about 10 minutes after checkout).

After you start a trial

  1. Wait for the hub. The success page watches the build and shows an Open button plus a QR code when it answers — usually around 10 minutes.
  2. Sign in as owner. Open {your-name}.lovely-hub.com. Cloudflare emails a one-time code to the address you used at signup.
  3. Walk through the wizard. Hub name, contacts, Wi‑Fi, lockbox, bins, optional calendar, and a starter house guide.
  4. Set an owner PIN. That is what unlocks owner tools on the wall tablet.
  5. Put it on the tablet. Open the hub URL, then either add it to the home screen, or set it as the start URL in Fully Kiosk.

Wall tablet (Fully Kiosk)

Fully Kiosk Browser (Android) keeps the hub fullscreen and awake. It is a separate app with its own licence — not part of Lovely Home.

  1. Install Fully and turn on Remote Admin (local network) with a password before you lock kiosk mode.
  2. Set the start URL to your hub, for example https://rose-cottage.lovely-hub.com.
  3. Keep cookies. If Fully clears cookies on reload, Cloudflare will ask for a login code every time the screen wakes.
  4. Choose an exit gesture and kiosk PIN, write them down, then enable kiosk mode.
  5. On the hub, enable House sitter mode on that device before you mount it.

Prefer not to use Fully? Chrome or Safari “Add to Home Screen” is enough for a simpler setup.

Invite a sitter

  1. Scheduled stay (usual). Settings → House sitter mode → add their email and dates. They can sign in from a few days before; Wi‑Fi and lockbox show on the stay dates; access drops after the stay ends.
  2. Wall tablet only. Leave the tablet in sitter mode. Turn on Sitter is here while someone is staying so home-access details appear.
  3. Long-term sitter. Add their email as a permanent sitter login — not for one-off visits.

Sitters never see the guide editor, backups, or home-control buttons. How access is locked down.

Stuck?

Email support@lovely-home.co.uk with your hub address. We cannot reset a tablet kiosk PIN — keep that with your household notes.
